# AI 协作与代码规范

## 1. 团队AI协作规则
- 所有通过AI生成的核心业务代码，必须有明确的注释说明其作用和逻辑。
- AI生成的代码需经过人工审核，确保逻辑合理、安全、无明显bug。
- 每次使用AI生成代码后，需在提交说明中简单标注（如：feat: 用户模块，部分代码由AI辅助生成并人工审核）。

## 2. 代码提交规范
- 提交信息格式：`类型: 描述`
  - `feat`：新增功能
  - `fix`：修复bug
  - `docs`：文档修改
  - `refactor`：代码重构（不影响功能）
  - `chore`：初始化、配置文件等杂项修改
- 禁止提交无意义的提交信息（如“修改”“更新”）。

## 3. 分支管理规范
- 主分支 `main` 为受保护分支，禁止直接推送代码。
- 开发需新建个人分支，完成后通过 Pull Request（PR）合并到 `main`。
- PR需至少1名组员审核通过后，方可合并。

## 4. 团队协作约定
- 所有组员需遵守上述规范，共同维护仓库整洁。
- 重大修改需先在群里沟通，确认方案后再开发。
